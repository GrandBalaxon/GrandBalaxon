### Featured Projects

#### 🔄 [Transactions ETL Pipeline](https://github.com/GrandBalaxon/transactions-etl-pipeline)
An ETL pipeline that reads a bank statement from Excel, cleans it with pandas and loads it into a PostgreSQL star schema. Includes analytical SQL queries with CTEs and window functions, a Docker Compose setup, tests on an isolated database and CI in GitHub Actions.

#### 📚 [LibraryAPI](https://github.com/GrandBalaxon/LibraryAPI)
A comprehensive REST API for library management (Django, DRF). Features a 3-tier architecture (Work -> Edition -> BookCopy), JWT authentication, role-based access, audit trails (django-simple-history), and Docker/CI/CD integration.

#### ⏱️ [Habits-Tracker](https://github.com/GrandBalaxon/Habits-Tracker)
A REST API service for tracking habits with a built-in Telegram bot and delayed tasks using Celery and Redis. Fully containerized with Docker.
